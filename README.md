# lilbud

Lil Bud is a tamagotchi-inspired character written in Rust. He is a small animated face that smoothly morphs between expressions, drawn from face data generated by [lil bud maker](https://github.com/zapplebee/lilbudmaker).

He runs on a [Waveshare RP2040-LCD-1.28](https://www.waveshare.com/rp2040-lcd-1.28.htm) — a 240×240 round GC9A01A display on a tiny RP2040 board, worn like a pin. When docked via USB, the companion **dock UI** shows his face, lets you edit your identity card and status, and displays statuses collected from friends during IRL encounters.

## Architecture

Three components:

| Component | Language | Role |
|-----------|----------|------|
| **Firmware** | Rust (`embedded`) | Runs on the RP2040, drives the display, stores data on littlefs flash |
| **WebView host** | Rust (`webview`) | Native OS app — bridges the board over USB to the dock UI |
| **Dock UI** | TypeScript / Bun | Web interface — face preview, identity, status, collected statuses |

---

## Hardware

| Component | Part |
|-----------|------|
| MCU | Raspberry Pi RP2040 (dual-core Cortex-M0+, 133 MHz) |
| Board | [Waveshare RP2040-LCD-1.28](https://www.waveshare.com/rp2040-lcd-1.28.htm) |
| Display | GC9A01A — 240×240 round TFT, RGB565, SPI |
| Interface | SPI1 at 40 MHz |
| Flash | W25Q080 (2MB) |

#### SPI Pinout

| Signal | GPIO |
|--------|------|
| SCK    | 10   |
| MOSI   | 11   |
| RST    | 12   |
| DC     | 8    |
| CS     | 9    |
| BL     | 25   |

CS is held permanently LOW after reset. RST is pulsed (HIGH → 100ms → LOW → 100ms → HIGH) to hardware-reset the display before init.

## Dock UI

When lilbud is plugged in via USB, the WebView host connects to the board and loads the dock UI. The board streams face animation frames; the host forwards filesystem commands to the board's littlefs flash.

### What it shows

- **Face** — live animation streamed from the board, rendered on a round canvas matching the physical display
- **Identity card** — name and bio stored on the board (`/id_card.txt`), editable in place
- **Actions** — feed / play / sleep buttons that write to `/action.txt` on the board
- **Your status** — short text you broadcast (`/status.txt`); tap to edit
- **Collected** — statuses received from friends during IRL exchanges (`/collected/<name>.txt`); dismissable

### Status exchange

When two lilbuds meet IRL, they swap statuses: each board broadcasts its `/status.txt` and writes the other's into `/collected/`. No server — all data lives on-device.

## Face Data Pipeline

```mermaid
sequenceDiagram
    participant LBM as lil bud maker
    participant NDJSON as lilbudz.ndjson
    participant Gen as gen_faces.ts
    participant FD as src/face_data.rs
    participant Cargo as cargo build

    LBM->>NDJSON: export face sessions
    NDJSON->>Gen: make faces FACE_FILE=lilbudz.ndjson
    Gen->>FD: pub static FACE_DATA: &[[(i32,i32); 18]]
    FD->>Cargo: compiled into binary
```

### Face Point Map

| Points | Feature |
|--------|---------|
| `a`, `b`, `c`, `d` | Head quad |
| `e-f`, `g-h`, `i-j`, `k-l`, `m-n`, `o-p` | Face line segments |
| `q`, `r` | Eyes |

---

## Animation

Each frame, every point in `FACE` steps 2px toward `TARGET`. A new `TARGET` is picked every 3 seconds. Per-frame jitter (1–5px) gives a wobbly, alive quality.

The dock UI mirrors this with a 30fps RAF loop and the same `interp(start, target, step=2)` function.

## Build

See **[BUILDING.md](BUILDING.md)** for prerequisites and flash instructions.

```sh
make faces      # regenerate face data
make webview    # WebView host (dev)
make app        # lilbud.app (macOS release)
make dist       # lilbud.app + zip
make dock-mock  # dock UI with mock data (http://localhost:3000)
make dock       # dock UI for real board
make embedded   # RP2040 firmware
make flash      # build + flash to /Volumes/RPI-RP2
make clean
```
